# Security Policy

## Supported versions

Only the latest release gets fixes.

## Reporting a problem

If you find a security problem (for example a way to crash or exploit a server through this mod), please **do not open a public issue**.

Report it privately with GitHub's [private vulnerability reporting](https://github.com/SenDeliver/create-aeronautics-landing-legs/security/advisories/new) for this repository. If that is not available, open an issue that only asks for a private contact, without details.

Please include the mod version, the versions of Minecraft, NeoForge, Create, Create Aeronautics and Sable, and steps to reproduce. You should get an answer within a few days.
