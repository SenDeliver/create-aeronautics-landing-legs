# Legs are a Leg Mount block plus a Limb item

A Leg is a Leg Mount block with a Limb item fitted onto it, mirroring how Aeronautics' Wheel Mount takes tire items. We chose this over one fixed block per Leg type because it matches an existing Aeronautics pattern players already know, gives real size choices for small and large Ships, and lets new Limbs (including ones from other mods) be added without new blocks. The cost is more items and saved per-Mount Limb data, which makes the choice expensive to undo once worlds contain Legs.
